## 📖 เกี่ยวกับระบบ (Overview)
ระบบจองห้องประชุมออนไลน์อัจฉริยะ (Smart Meeting Room Booking System) พัฒนาขึ้นเพื่อยกระดับการบริหารจัดการห้องประชุมและสิ่งอำนวยความสะดวกของ **วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์** ให้มีความสะดวกรวดเร็ว แม่นยำ ป้องกันการใช้ห้องซ้ำซ้อน และรองรับระเบียบแบบแผนทางราชการอย่างสมบูรณ์แบบ

## ✨ คุณสมบัติเด่นของระบบ (Core Features)

### 1. ข้อมูลห้องประชุมหลัก (6 ห้อง + อื่นๆ)
- 🏛️ **หอประชุมอดิเรกสาร** (ความจุ 500 - 800 คน) - พิธีการใหญ่ สัมมนา ปฐมนิเทศ
- 🌲 **ห้องประชุมสักทอง** (ความจุ 50 - 80 คน) - ประชุมคณะกรรมการ ประชุมแผนก
- 👔 **ห้องประชุมหน้าห้องผู้อำนวยการ** (ความจุ 20 - 30 คน) - ประชุมผู้บริหาร แขกวีไอพี
- ☕ **ห้องประชุม (กาแฟ)** (ความจุ 15 - 20 คน) - บรรยากาศเป็นกันเอง ประชุมกลุ่มย่อย
- 🏟️ **อาคารโดมเอนกประสงค์** (ความจุ 1,000+ คน) - กิจกรรมนักเรียนนักศึกษา กีฬา นิทรรศการ
- 💻 **ห้องคอมพิวเตอร์กลาง (ห้องโสต)** (ความจุ 40 - 60 คน) - อบรมดิจิทัลและเทคโนโลยี
- 📍 **อื่นๆ** (สามารถระบุชื่อสถานที่เพิ่มเติมได้ตามต้องการ)

### 2. ฟอร์มบันทึกคำขอจอง & ระบบตรวจจับเวลาซ้ำซ้อนแบบ Real-time (Conflict Detection)
- บันทึกข้อมูลผู้ขอใช้: ชื่อ-นามสกุล, ตำแหน่ง, แผนกวิชา/งาน, หมายเลขโทรศัพท์
- บันทึกรายละเอียดการจอง: ห้องประชุม, วันที่เริ่ม-สิ้นสุด, เวลาเริ่ม-สิ้นสุด, จำนวนผู้เข้าใช้
- ระบุครุภัณฑ์/สิ่งอำนวยความสะดวก: เครื่องฉายภาพ, ระบบเสียง, ไมโครโฟน (ระบุจำนวนตัว), เครื่องปรับอากาศ, อินเทอร์เน็ต Wi-Fi, โต๊ะ/เก้าอี้เพิ่มเติม (ระบุจำนวน)
- **ระบบ Conflict Detection แบบทันที**: หากมีการเลือกห้องและช่วงเวลาที่ตรงกับคำขออื่นที่ได้รับการอนุมัติหรืออยู่ระหว่างการพิจารณา ระบบจะแจ้งเตือนพร้อมแสดงรายละเอียดการชน และปิดการส่งฟอร์มเพื่อป้องกันข้อผิดพลาด 100%

### 3. ระบบอนุมัติตามลำดับขั้นราชการ 4 ขั้นตอน (Multi-Level Approval Workflow)
- **ขั้นที่ 1:** ผู้ขอใช้ยื่นแบบฟอร์มเข้าสู่ระบบออนไลน์
- **ขั้นที่ 2:** เจ้าหน้าที่ตรวจสอบห้อง (**นายวัชรพงศ์ โสภา** - เจ้าหน้าที่งานศูนย์ดิจิทัลและสื่อสารองค์กร) ตรวจสอบความพร้อมใช้งานของห้องและอุปกรณ์
- **ขั้นที่ 3:** หัวหน้างาน/ผู้รับรอง (**นายเอกราช เขียวทอง** - หัวหน้างานศูนย์ดิจิทัลและสื่อสารองค์กร) ลงนามรับรองคำขอ
- **ขั้นที่ 4:** ผู้พิจารณาอนุมัติ (**นายชาตรี เริงชัยภูมิ** - รองผู้อำนวยการฝ่ายพัฒนายุทธศาสตร์และแผนงาน) อนุมัติ / ไม่อนุมัติ
- รองรับการเซ็นชื่อดิจิทัล (Digital Signature Pad) บนหน้าจอสัมผัสหรือเมาส์

### 4. หน้าแดชบอร์ดสรุปผลเชิงภาพ (Interactive Dashboard)
- การ์ดสรุปตัวเลขสถิติ: ใช้ห้องวันนี้, รออนุมัติ, อนุมัติแล้ว, รวมทั้งหมด
- กราฟแท่ง (Bar Chart): สถิติความถี่การใช้งานห้องประชุมแต่ละห้อง
- กราฟโดนัท (Donut Chart): สถิติการขอใช้อุปกรณ์/สิ่งอำนวยความสะดวก
- ตารางรายการจองล่าสุด พร้อมระบบค้นหาและตัวกรองสถานะ

### 5. ปฏิทินแสดงสถานะห้องประชุม (FullCalendar.js)
- มุมมอง: รายเดือน (Month), รายสัปดาห์ (Week), รายวัน (Day), และรายการ (List)
- จำแนกสีตามห้องประชุมทั้ง 6 ห้องหลักอย่างชัดเจน
- ตัวกรองห้องประชุม (Filter by Room)
- คลิกที่กิจกรรมในปฏิทินเพื่อดูรายละเอียดผู้ขอใช้ วัตถุประสงค์ และไทม์ไลน์การอนุมัติได้ทันที

### 6. แบบฟอร์มราชการขนาด A4 และการส่งออกข้อมูล
- **พิมพ์แบบคำขอใช้ห้องประชุมมาตรฐานราชการ A4**: ออกแบบตามโครงสร้างเอกสารของวิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ พร้อมตราสัญลักษณ์ และช่องลงนามครบทั้ง 4 ฝ่าย
- **ส่งออก CSV (UTF-8 BOM)**: รองรับการเปิดใน Microsoft Excel ภาษาไทย 100% โดยตัวอักษรไม่เป็นภาษาต่างดาว
- **ส่งออก Excel Spreadsheet (.xls)**: รูปแบบตารางสวยงามพร้อมจัดพิมพ์

### 7. ระบบแจ้งเตือน Real-Time Notification & Webhook
- จำลองเสียงกระดิ่งเตือนผ่าน **Web Audio API** โดยตรง ไม่ต้องพึ่งพาไฟล์เสียงภายนอก
- In-App Toast แจ้งเตือนสถานะ
- รองรับ **Webhook**: เชื่อมต่อไปยัง Discord, Telegram Bot, Google Chat หรือ Custom API เมื่อมีการยื่นคำขอใหม่หรือมีการอัปเดตสถานะ

### 8. โทนสีและดีไซน์ (Identity Theme) & Google Sheets Viewer
- ออกแบบตามสีประจำวิทยาลัย: **แดง (Red) / ฟ้า-น้ำเงิน (Blue) / เหลืองทอง (Gold) / ขาว (White)**
- สะอาดตา เข้าใจง่าย ใช้งานสะดวกทั้งบนสมาร์ทโฟน แท็บเล็ต และคอมพิวเตอร์
- **ปุ่ม "ดู Google Sheets":** กดเพื่อดูตารางข้อมูลสด (Live Spreadsheet Grid) ได้ทันทีจากหน้าเว็บ พร้อมปุ่มเปิดไปยัง Google Sheets จริงและปุ่มคัดลอกเทมเพลตเข้า Google Drive
- **เมนูตั้งค่าระบบ (Settings):** แยกออกจากแถบเมนูหลักเพื่อความเรียบร้อย สามารถกดเข้าผ่านปุ่มไอคอนรูปฟันเฟือง (⚙️) ที่มุมขวาบนของหน้าเว็บได้ตลอดเวลา

## 💻 วิธีการเปิดใช้งาน (Getting Started)

### วิธีที่ 1: เปิดใช้งานบนเครื่องคอมพิวเตอร์ทันที (Offline-First)
1. ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari)
2. ระบบจะโหลดข้อมูลตัวอย่างพร้อมใช้งานได้ทันที 100% โดยบันทึกข้อมูลใน LocalStorage ของเบราว์เซอร์

### วิธีที่ 2: เผยแพร่ผ่าน GitHub Pages (ฟรี 100%)
1. นำไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นสู่ GitHub Repository ของท่าน
2. ไปที่ **Settings** > **Pages**
3. ที่ส่วน **Build and deployment** ให้เลือก Branch เป็น `main` และ Folder เป็น `/ (root)` แล้วกด **Save**
4. รอประมาณ 1 นาที จะได้ลิงก์เว็บไซต์ใช้งานได้จริง เช่น `https://username.github.io/repository-name/`

### วิธีที่ 3: เชื่อมต่อ Google Sheets เป็นฐานข้อมูล Cloud
1. ดูคู่มืออย่างละเอียดในไฟล์ [`google_sheets_backend/SETUP_GUIDE.md`](google_sheets_backend/SETUP_GUIDE.md)
2. นำ URL ที่ได้จาก Google Apps Script Web App มาใส่ในแท็บ **"Google Sheets & Webhook"** บนหน้าเว็บ แล้วกด **"บันทึกการเชื่อมต่อ"**

## 👥 ผู้รับผิดชอบในกระบวนการพิจารณาอนุมัติ
1. **ผู้ขอใช้:** ข้าราชการครูและบุคลากรทางการศึกษา วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์
2. **เจ้าหน้าที่ตรวจสอบห้อง:** นายวัชรพงศ์ โสภา (เจ้าหน้าที่งานศูนย์ดิจิทัลและสื่อสารองค์กร)
3. **หัวหน้างานผู้รับรอง:** นายเอกราช เขียวทอง (หัวหน้างานศูนย์ดิจิทัลและสื่อสารองค์กร)
4. **ผู้พิจารณาอนุมัติ:** นายชาตรี เริงชัยภูมิ (รองผู้อำนวยการฝ่ายพัฒนายุทธศาสตร์และแผนงาน)
