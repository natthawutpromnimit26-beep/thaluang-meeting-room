# คู่มือการติดตั้ง Google Sheets Backend API
## ระบบจองห้องประชุมออนไลน์ (Smart Meeting Room Booking System)
### วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์

ระบบนี้ถูกออกแบบให้สามารถทำงานร่วมกับ **Google Sheets** เพื่อใช้เป็นฐานข้อมูล Cloud Database ฟรี 100% ปลอดภัย บันทึกข้อมูลแบบ Real-time และสามารถเปิดดูผ่านมือถือหรือคอมพิวเตอร์ได้ตลอดเวลา

---

### ขั้นตอนการตั้งค่า Google Sheets (ใช้เวลาเพียง 3 นาที):

#### 1. สร้าง Google Sheets ใหม่
1. ไปที่ [Google Sheets](https://sheets.new) แล้วสร้างสเปรดชีตเปล่าใหม่
2. ตั้งชื่อไฟล์สเปรดชีต เช่น `ระบบจองห้องประชุม วิทยาลัยเทคนิคท่าหลวงฯ`

#### 2. เปิดตัวแก้ไข Apps Script
1. ที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** > **Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกให้หมด
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `google_sheets_backend/Code.gs` (หรือกดดูจากหน้าต่างการตั้งค่าบนหน้าเว็บ) แล้ววางลงไป
4. กดไอคอน **บันทึกโครงการ (Save Project)** (รูปแผ่นดิสก์) หรือกด `Ctrl + S`

#### 3. เผยแพร่เป็น Web App (Deploy)
1. ที่มุมขวาบน คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)**
2. คลิกที่รูปเฟืองข้างคำว่า "เลือกประเภท (Select type)" แล้วเลือก **เว็บแอป (Web app)**
3. กรอกรายละเอียดดังนี้:
   - **คำอธิบาย (Description):** `API ระบบจองห้องประชุม v1.0`
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (อีเมลของคุณ)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(สำคัญมาก ต้องเลือก Anyone เพื่อให้หน้าเว็บส่งและดึงข้อมูลได้โดยไม่ต้องล็อกอิน)*
4. คลิก **ทำให้ใช้งานได้ (Deploy)**
5. หากมีหน้าต่างขอสิทธิ์การเข้าถึง (Authorization Required) ให้คลิก:
   - **ตรวจสอบสิทธิ์ (Authorize access)**
   - เลือกบัญชี Google ของท่าน
   - หากเจอข้อความแจ้งเตือน "Google ยังไม่ได้ยืนยันแอปนี้ (Google hasn't verified this app)" ให้คลิก **ขั้นสูง (Advanced)** ที่มุมล่างซ้าย > คลิก **ไปที่ [ชื่อโปรเจกต์] (ไม่ปลอดภัย)**
   - คลิก **อนุญาต (Allow)**

#### 4. คัดลอก Web App URL ไปใส่ในหน้าเว็บ
1. หลังจาก Deploy เสร็จ ระบบจะแสดง **URL ของเว็บแอป (Web App URL)** ขึ้นต้นด้วย:
   `https://script.google.com/macros/s/AKfycb.../exec`
2. คัดลอก (Copy) ลิงก์ดังกล่าว
3. เปิดหน้าเว็บไซต์ระบบจองห้องประชุม > ไปที่แท็บ **"Google Sheets & Webhook"**
4. วาง URL ลงในช่อง **Google Apps Script Web App URL** แล้วกด **"บันทึกการเชื่อมต่อ"**
5. กดปุ่ม **"ทดสอบดึงข้อมูล (Sync)"** หากสำเร็จ ระบบจะแจ้งเตือนว่าซิงค์ข้อมูลเรียบร้อย

### โครงสร้างคอลัมน์ใน Google Sheets:
เมื่อระบบเริ่มซิงค์ข้อมูล แผ่นงาน `Bookings` จะถูกสร้างขึ้นอัตโนมัติพร้อมหัวตารางดังนี้:
1. **เลขที่คำขอ (ID):** เช่น `REQ-26-1001`
2. **ห้องประชุม:** เช่น หอประชุมอดิเรกสาร, ห้องสักทอง
3. **ผู้ขอใช้:** ชื่อ-นามสกุล, ตำแหน่ง, แผนกวิชา
4. **วันและเวลาที่ใช้งาน:** วันที่เริ่ม-สิ้นสุด และเวลา
5. **จำนวนผู้เข้าใช้:** จำนวนคน
6. **สถานะรวม:** อนุมัติเรียบร้อยแล้ว, รอเจ้าหน้าที่ตรวจสอบ, รอหัวหน้างานรับรอง, รอรอง ผอ. อนุมัติ
7. **สถานะรายขั้นตอน (4 ขั้นตอน):** แสดงสถานะการผ่านการพิจารณาของแต่ละท่าน
